# Shuffle roadmap

What is being worked on and what comes after. The order is driven by your
votes: every planned item links to a GitHub discussion — open it and hit
the **⬆ upvote** button. Propose new ideas (or argue for moving something
up) at https://github.com/WizenPainter/shuffle/discussions/categories/ideas.

This file also powers the Roadmap section on https://www.shuffleapp.co.
Format rules the website parser expects:

- Sections are `## Now`, `## Next`, `## Later` (up to 4 sections shown).
- Items are `- [ ] Title` (planned) or `- [x] Title` (shipped).
- Anything after ` - ` in an item becomes a small gray note.

## Now

- [x] Signed and notarized releases
- [x] In-app self-updater - updates now keep your permissions
- [x] Tabs and split panes with precise drag & drop
- [x] Live folder refresh - new downloads appear instantly
- [x] Search upgrades - content search + kind/ext/size/date filters in filter & palette
- [x] Script actions - run your own shell scripts from the right-click menu
- [ ] Smoother, more premium feel everywhere - vote: github.com/WizenPainter/shuffle/discussions/1

## Next

- [x] First-class SFTP connections - saved servers, remote previews, sidebar
- [x] Better cloud drive integration - sync badges, download-on-demand, free up space
- [ ] More Quick Actions per file type - batch rename, convert, PDF tools - vote: github.com/WizenPainter/shuffle/discussions/2
- [ ] Restore tabs & split layout on launch - vote: github.com/WizenPainter/shuffle/discussions/6

## Later

- [ ] Discover Macs & servers on the local network - Bonjour/SMB - vote: github.com/WizenPainter/shuffle/discussions/5
- [ ] Preview more file types & archive browsing - vote: github.com/WizenPainter/shuffle/discussions/7
- [ ] Richer plugin runtime - embedded Lua or WASM, evaluated as a follow-up to script actions
- [ ] Localization
- [ ] Maybe: a one-time Pro purchase - never a subscription
